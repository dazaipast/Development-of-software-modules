# Text Kit

Учебный набор функций для строк, дат, расчётов и проверки данных. Программа берёт готовые примеры и печатает по ним короткий отчёт: заголовок, оценки, почту, телефоны, пароли и две даты.

## По какому признаку разделены модули

Функции разделены по теме.

В `app/utils/` лежат мелкие функции, которые пригодятся в любом проекте: работа со строками и с датами. В `app/services/` лежат правила этого проекта: расчёты по числам и проверка почты, телефона и пароля. `app/main.py` ничего не считает сам — только вызывает готовые функции и печатает результат.

## Дерево проекта

```
text-kit/
  README.md                  описание проекта, запуск и ожидаемый вывод
  ЗАДАНИЕ.md                 условие практической работы
  app/__init__.py            делает app пакетом
  app/main.py                точка запуска: примеры данных и печать отчёта
  app/utils/__init__.py      делает utils пакетом
  app/utils/text.py          пробелы, сокращение строки, инициалы, адрес страницы
  app/utils/dates.py         разбор даты, запись даты, выходной, дни между датами
  app/services/__init__.py   делает services пакетом
  app/services/statistics.py среднее, медиана, разброс, подсчёт значений
  app/services/validation.py почта, телефон и замечания к паролю
  tests/                     проверки функций, 19 тестов
```

## Запуск

Команды выполняются из корня проекта:

```
python -m app.main
python -m unittest discover -s tests -v
```
